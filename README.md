## ✨ Features

- 🎬 **Interactive Story Slides** — Navigate through beautiful, animated slides telling a personalized story
- 🎵 **Background Audio** — Immersive audio experience synchronized with content
- 📱 **Mobile-First Design** — Optimized for mobile viewing with responsive container layout
- ⚡ **Smooth Animations** — Powered by Framer Motion for fluid transitions and effects
- 🎨 **Modern UI/UX** — Beautiful gradients, progress indicators, and intuitive navigation
- 🎉 **Confetti Celebration** — Special celebratory effects for key moments

## 🚀 Getting Started

### Prerequisites

- Node.js ≥ 18.x
- npm or yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/larddbae/loves-birthday.git
   cd loves-birthday
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm run dev
   ```

4. **Open in browser**
   ```
   http://localhost:5173
   ```

## 🎨 Story Slides

The application features 11 beautifully crafted slides:

1. **Start** — Welcome screen with call-to-action
2. **Intro** — Introduction to the story
3. **Minutes** — Time spent together
4. **Peak Hours** — Most active moments
5. **Anthem** — Special soundtrack
6. **On Repeat** — Favorite memories on loop
7. **Habits** — Personal quirks and habits
8. **Aura** — Personality and vibe
9. **Up Next** — What's coming next
10. **Reveal** — The big reveal
11. **Outro** — Closing message with celebration
